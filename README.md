# Fruitopia 🍎🍊
### Final Project Web Design LEC

**Fruitopia**  is a Fruit E-commerce website built using **React** designed to provide users with a seamless and enjoyable online fruit shopping experience. Users can browse a wide variety of fresh fruits, view detailed product information, add items to their cart, and manage their purchases efficiently through a clean and intuitive interface.
<br><br>

## Features
- **Secure user authentication using Supabase Auth** with login and registration functionality
- **Landing Page** that introduces Fruitopia and highlights featured products with a clean and user-friendly interface
- **Shop Page** displaying a collection of fruits available for purchase in an organized product listing 
- **Product Detail Pages** providing detailed information for each fruit, including the ability for users to select their desired purchase quantity
- **Add to Cart Functionality** allowing users to add selected fruits to their shopping cart seamlessly
- **Shopping Cart & Checkout System** enabling users to review their selected items and complete purchases efficiently
- Built with **React** and **Tailwind CSS** for a responsive and dynamic e-commerce experience
